# Plano de Aulas: Curso de Git

## 1ª Aula

### Teoria
* **Contexto do Curso:** Apresentação geral e explicação dos conceitos fundamentais.
* **Git - Inicialização:** 
  * Entendendo as complexidades iniciais.
  * Orientações sobre a conta no GitHub.

### Prática
* **Contextualização Prática:** Desenvolvimento de um projeto simples para aplicar a teoria.
* **Mão na massa:** Como salvar as alterações no Git.

---

## 2ª Aula

### Início
* **Iniciar Git:** Configuração inicial no novo repositório.
* **Projeto Principal:** Início do desenvolvimento de um projeto *TodoList* (Lista de Tarefas).
* **Versionamento:** Realização do 1º versionamento no Git.

### Continuação
* **Desenvolvimento:** Continuação das atividades do projeto.
* **Versionamento:** Realização do 2º versionamento para registrar o progresso.
