# Proposta de Curso

Como segunda atividade de extensão pós-semana acadêmica 2026,

Propõe-se a realização de um curso introdutório sobre o framework **Vue.js e GitHub**, destinado aos alunos do **2º semestre TADS 2026**, 
com o objetivo de proporcionar conhecimentos práticos relacionados ao desenvolvimento de aplicações web e ao 
uso de ferramentas de versionamento e colaboração em projetos de software.

O curso será composto por duas aulas, abordando de forma integrada os conceitos fundamentais do framework Vue.js 
e os principais recursos do GitHub para gerenciamento e compartilhamento de projetos. 
A proposta busca aproximar os alunos de ferramentas amplamente utilizadas no desenvolvimento de software, 
permitindo que tenham contato com práticas presentes no mercado e em projetos acadêmicos.

Ao final do curso, espera-se que os alunos tenham adquirido uma compreensão inicial sobre o desenvolvimento de aplicações utilizando Vue.js 
e sejam capazes de utilizar o GitHub para armazenar, versionar e compartilhar seus projetos. 
Dessa forma, a atividade pretende contribuir para o desenvolvimento das competências técnicas dos estudantes 
e para sua preparação para atividades acadêmicas e profissionais relacionadas ao desenvolvimento de software.
